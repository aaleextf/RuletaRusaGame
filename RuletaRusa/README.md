## Juego Principal

Este juego es una inspiracion de Buckshot Roulette, esta version se basa en la ruleta rusa basica pero para consola, respetando turnos y vidas, actualmente en desarrollo para poseriormente añadirle interfaz gráfica.
Desarrollado en Java en poryecto No Tools.



## Como jugar

Primero nos va a preguntar que cuantos jugadores vamos a ser(2-4)
Vamos a introducir el numero de jugadores: 
3

Nos va a preguntar el nombre de cada jugador, le introducimos cada nombre y posteriormente nos va a mostrar una lista de los jugadores, muy importante saber que el orden de juego se sigue en base a la lista de nombres.

De forma aleatoria va a elegir el programa a un jugador y ese mismo va a empezar, en cuanto acabe su turno pasa al siguiente y asi en bucle hasta que todos los jugadores menos uno alcance 0 vidas, ahi se para el bucle y se cierra el juego con un mensaje en pantalla indicando que has ganado.
